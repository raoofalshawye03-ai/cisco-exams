# Cisco Networking Comprehensive Mock Exam

Interactive Cisco networking mock exam in English.

## GitHub Pages

Repository:
`raoofalshawye03-ai/cisco-exams`

Files to upload to the repository root:
- `index.html`
- `robots.txt`
- `sitemap.xml`
- `.nojekyll`

Then enable GitHub Pages:
1. Open the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: **main**
5. Folder: **/(root)**
6. Click **Save**.

Expected public URL:
https://raoofalshawye03-ai.github.io/cisco-exams/

## Search indexing

After the site is public, add the URL to Google Search Console and submit:
`https://raoofalshawye03-ai.github.io/cisco-exams/sitemap.xml`
